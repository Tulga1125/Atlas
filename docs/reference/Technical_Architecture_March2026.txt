 SECTION 1




 Executive Summary
 Atlas Charts is Mongolia's first official, cross-platform music chart system — modeled after Billboard (USA), Official
 Charts (UK), and Gaon/Circle Chart (South Korea). It aggregates streaming data from Spotify, Apple Music, YouTube
 Music, and local Mongolian streaming platforms to rank every song consumed in Mongolia across five time windows:
 hourly, daily, weekly, monthly, and yearly.

 Unlike simple popularity lists, Atlas Charts uses a weighted scoring model that accounts for platform market share,
 subscription tier quality, and Mongolia's unique streaming market characteristics. The result is a single, trustworthy
 ranking that reflects real Mongolian listening behavior — not algorithmic curation or any single platform's bias.


   KEY CAPABILITIES

   • Ingest and normalize streaming data from 4+ platforms in near real-time
   • Rank songs across 5 chart periods: Hourly, Daily, Weekly, Monthly, Yearly
   • Apply a transparent, auditable weighted scoring algorithm (the Atlas Score)
   • Detect and filter fraudulent streaming activity via rules engine
   • Publish chart data via REST API, web portal, and broadcast-ready formats
   • Support both global songs streamed in Mongolia and a dedicated Mongolian-language sub-chart
   • Full historical auditability — every chart snapshot is immutable and permanently stored




 Why Atlas Owns This Software
  • No dependency on any third-party chart company — Atlas owns the algorithm, the data, and the brand
  • The software is an asset that can be licensed to other small countries building their own chart systems
  • Data becomes a moat: 5 years of Mongolian streaming history is impossible to recreate once Atlas owns it
  • Billboard and Circle Chart partnerships become partnerships of equals — Atlas brings data, not just brand
  • IFPI recognition and official national chart status require proprietary infrastructure — not a licensed tool

 SECTION 2




 System Architecture — Five Layers
 The Atlas Charts system is composed of five logical layers. Each layer has a distinct responsibility, can be
 independently scaled, and communicates with adjacent layers through well-defined interfaces. All layers communicate
 through Apache Kafka as the internal message broker.


 Lay       Name                           Responsibility
 er

 1         Data Ingestion                 Connects to streaming APIs; pulls raw stream events from each platform

 2         Normalization & Validation     Standardizes formats; deduplicates events; detects and quarantines fraud

 3         Scoring Engine                 Applies weighted scoring formula; computes Atlas Scores per track

 4         Chart Aggregation              Produces ranked lists per time window; stores immutable historical snapshots

 5         Publishing & Distribution      Exposes charts via REST API, web portal, and broadcaster partner feeds




 Layer 1 — Data Ingestion
 Each streaming platform has a dedicated Connector microservice. Connectors are stateless workers that authenticate,
 poll or subscribe to platform APIs, and forward raw events to Kafka. Geo-filtering is applied at ingestion: only streams
 where the listener's IP/account country is Mongolia (ISO code: MN) are counted. This is enforced at the API query
 level and validated again in the normalization layer.


 Platform                         Integration Method                                  Refresh Interval

 Spotify                          Spotify Charts API / Streaming API                  Every 15 minutes

 Apple Music                      MusicKit API + Charts endpoint                      Every 15 minutes

 YouTube Music / YouTube          YouTube Data API v3 + Analytics                     Every 30 minutes

 Local Mongolian Platforms        Direct API partnership / data export                Every 60 minutes (negotiated)
 (MMusic, Sonsy)




 Layer 2 — Normalization & Fraud Detection

 Track Identity Resolution
 The same song may appear under different IDs across platforms. Atlas Charts resolves track identity using the
 International Standard Recording Code (ISRC) as the canonical key. Every track is assigned a single Atlas Track ID
 (ATID).

  • If ISRC present: look up or create ATID in track registry
  • If no ISRC: fuzzy match on artist name + track title + duration
  • If no match: create provisional ATID pending manual review

 Layer 3 — The Scoring Engine

 The Atlas Score Formula

   ATLAS SCORE FORMULA
   Atlas Score = Σ ( stream_quality_weight × platform_market_weight × stream_value )

   Where:
   stream_value = 1.0 for any qualifying stream (≥30 seconds, from Mongolia)
   stream_quality_weight = subscription tier multiplier (see table below)
   platform_market_weight = normalized platform weight (see table below)

   Weights are published publicly and reviewed semi-annually.
   Any changes are announced at least 30 days in advance.
   This transparency is what makes Atlas Charts trustworthy and defensible as Mongolia's
   official chart when seeking IFPI recognition or Billboard partnership.

 SECTION 4




 Layer 4 — Chart Aggregation & Time Windows
 The Chart Aggregation layer reads Atlas Scores from the scoring engine and produces ranked lists for each of five
 time windows. Every chart publication is written as an immutable snapshot — snapshots are never overwritten.
 Corrections are applied as amendment records, enabling full auditability and historical lookup for any date in Atlas
 Charts history.


 Chart Period           Window Definition                   Update Frequency                 Chart Size

 Hourly                 Rolling 60-minute window            Every 15 minutes                 Top 20

 Daily                  Midnight to midnight (UTC+8)        Every 30 minutes                 Top 50

 Weekly                 Monday 00:00 to Sunday 23:59        Every hour                       Top 100
                        (UTC+8)

 Monthly                Calendar month (UTC+8)              Daily                            Top 100

 Yearly                 January 1 to December 31 (UTC+8)    Weekly during year               Top 200



 Chart Metadata per Entry
  • Current position + previous position (up / down / new entry indicator)
  • Peak position ever reached on this chart period
  • Number of weeks / months on chart (longevity tracking)
  • 7-day score trend (moving average) — shows momentum
  • Platform contribution breakdown (% of Atlas Score from each source)
  • Listener demographic summary where available from platforms


 Sub-Chart: Mongolian-Language Filter
 A dedicated sub-chart tracks only songs where the primary language is Mongolian. Language classification is based
 on ISRC country prefix + manual editorial review. This sub-chart is published alongside the main chart and becomes
 the primary chart used for the Atlas Music Awards — ensuring Mongolian-language artists have their own definitive
 ranking, not just a share of the global chart.

 Scalability Notes
 The current architecture handles approximately 50–500 million streaming events per month — appropriate for
 Mongolia's market size. As streaming penetration grows, the system scales horizontally: additional Kafka partitions,
 Flink task slots, and ClickHouse shards. No architectural redesign is required to 10× the current load.

 International Chart Partnerships

 Billboard Partnership
 Billboard is owned by Penske Media Corporation and has an established international franchise and licensing model.
 Billboard Philippines launched through a licensing deal with a local media company. Billboard has expanded into
 Japan, Thailand, China (via YinYueTai), and Southeast Asia using the same model: a local media partner takes a
 content license, runs Billboard-branded content and charts, and pays a licensing fee.


     ATLAS–BILLBOARD PARTNERSHIP PROPOSAL
     Structure: Atlas Media LLC licenses the Billboard brand for Mongolia.
     Atlas operates 'Billboard Mongolia' — branded chart, editorial, and award shows.
     Atlas pays Billboard a licensing fee (typically 8–15% of gross revenue from
     Billboard-branded activities).
     In return: Atlas gets the Billboard brand credibility, access to Billboard's
     international data network, and official recognition in IFPI's global reporting chain.

     Contact pathway:
     1. Email Billboard's International Business Development at Penske Media Corp (PMC)
     2. Reference the Billboard Philippines model (Modern Media Group / MMGI, launched 2023)
     3. Unique position: Mongolia is an entirely unserved market — zero competition
     4. Propose a 3-year license with revenue share, not upfront fee, given market size

     Estimated licensing cost: MNT 2,000,000–5,000,000/year (depending on negotiated terms)
     Value unlocked: billboard.com/mongolia URL, internationally recognized chart,
     IFPI membership path for Atlas Data LLC

 Circle Chart / KMCA Partnership (Korea)
 The Korea Music Content Association (KMCA) operates Circle Chart — South Korea's official national chart, formerly
 known as Gaon Chart. KMCA became Korea's IFPI national representative in 2022 and is the official ISRC registrar for
 all K-pop music. KMCA has data partnerships with Spotify, Apple Music, YouTube, and TikTok.

 A partnership between Atlas Data LLC and KMCA / Circle Chart creates mutual value: Atlas gets access to the global
 K-pop data infrastructure and chart credibility; KMCA gets its first official Mongolian chart partner, extending Circle
 Chart's data reach into Central Asia — a region with significant K-pop consumption.


   ATLAS–CIRCLE CHART PARTNERSHIP PROPOSAL
   Structure: Data sharing agreement + co-branded 'K-pop in Mongolia' chart.
   Atlas Charts publishes weekly K-pop chart for Mongolia using Circle Chart data.
   Circle Chart/KMCA gains Mongolian market visibility and Central Asia reach.

   Contact pathway:
   1. Contact KMCA International Affairs division (contact published on kmca.or.kr)
   2. Reference Mongolia's K-pop consumption data from Atlas Charts V1
   3. Propose a mutual data exchange: Atlas MN data to KMCA; K-pop chart data to Atlas
   4. KOCCA (Korea Creative Content Agency) can co-fund via Hallyu export programs

   Additional angle: KOCCA funds international K-pop promotion. Atlas as an official
   Mongolian K-pop chart partner qualifies for KOCCA promotional grant funding.

 The Competitive Moat

   WHY THIS IS NEARLY IMPOSSIBLE TO REPLICATE IN YEAR 2+

   1. DATA HISTORY — 5 years of Mongolian streaming data is an asset that takes 5 years to build.
   No competitor can skip this. Atlas Charts starts building it on Day 1.

   2. FIRST MOVER AUTHORITY — The first chart to be recognized by IFPI, Billboard, and the
   Mongolian music industry IS the official chart. Second entrants face a legitimacy cliff.

   3. ARTIST ECOSYSTEM LOCK-IN — Artists, labels, and managers use the platform that
   matters for their careers. Once 50+ Mongolian artists are tracking their Atlas Charts
   positions weekly, switching costs are extremely high.

   4. MEDIA INTEGRATION — TV shows, radio, and digital media embed Atlas Charts widgets
   and reference Atlas Charts rankings. This creates a self-reinforcing citation network.

   5. IP OWNERSHIP — The scoring algorithm, the ATID track registry, and the historical
   snapshot archive are Atlas Data LLC's proprietary intellectual property.
